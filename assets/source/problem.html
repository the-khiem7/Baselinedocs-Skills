Without a pack
a long thread
Decisions, evidence and the next step live only in the chat.
compaction
Or a fresh chat, started from whatever was copied across.
a summary
It keeps that a rule existed, not what the rule said.
lost
The exact continuation point is gone.
With a pack
a long thread
The same work, in the same chat.
save
What the thread established goes into the pack.
onboard
Any new thread or agent reads the pack in full.
resume
At the recorded next action, with the decisions intact.
